## 📄 Descripción del Proyecto
**MammoInsight** es una iniciativa de salud digital iniciada a **principios de 2023**, enfocada en la detección temprana del cáncer de mama mediante Inteligencia Artificial. La plataforma web actúa como el punto central de acceso a nuestras herramientas de análisis de imágenes (modelos de Deep Learning), recursos educativos de prevención y datos abiertos para la comunidad científica.
### Características Técnicas del Sitio
*   **Arquitectura:** Sitio web estático (HTML5 Semántico / CSS3 Puro).
*   **Optimización:** Estructura ligera diseñada para tiempos de carga mínimos y alta compatibilidad.
*   **Seguridad:** Integración segura con iframes y recursos externos (Archive.org, Google Forms).
